# Classo · UML 类图工具

一个不依赖任何框架或外部资源的 UML 类图编辑器，使用原生 HTML + CSS + JavaScript 编写。直接双击 `index.html` 即可使用。

## 功能

- **元素类型**：可创建类、接口、抽象类和枚举，并在右侧属性面板中随时切换
- **类型化面板**：接口配置方法，类与抽象类配置属性和方法，枚举使用独立的枚举值列表
- **画布表现**：接口自动显示 `«interface»`，枚举显示 `«enumeration»`，抽象类显示 `«abstract»` 且名称使用斜体
- **结构化成员编辑**：属性和方法通过表单添加与编辑，修饰符用下拉选择，无需手动输入 `+ - # ~` 符号
- **多参数方法**：点击「添加参数」可为方法逐个添加参数，参数会自动以逗号连接；也可在参数框中按回车继续添加
- **六种关系**：关联、继承/泛化、实现、聚合、组合、依赖
- **关系属性**：类型、标签、两端重数，可一键交换方向
- **智能排版**：自动选择连接边、正交折线、自动绕让；拖动时吸附对齐并显示参考线
- **画布操作**：自由平移、滚轮缩放、适应画布
- **编辑体验**：撤销 / 重做、删除、方向键微调、自动保存到浏览器
- **文件**：导入 / 导出 JSON，导出 SVG 与 2× PNG
- **界面**：简洁浅色主题，桌面与窄屏自适应

## 使用

1. 打开 `index.html`，首次进入会显示一张示例图。
2. 点击右上角「新建元素」或双击画布空白处添加元素，然后在右侧选择元素类型。
3. 在右侧属性面板中填写元素名称，并从「元素类型」中选择类、接口、抽象类或枚举。
4. 类与抽象类可配置属性和方法；接口配置方法；枚举使用「枚举值」列表。方法参数可通过「添加参数」逐条增加，节点中会自动用逗号分隔。
5. 点击左侧「关系」中的类型，再依次点击起点元素和终点元素即可连线。
6. 选中连线后可在右侧修改关系类型、标签与重数。
7. 所有修改都会自动保存在当前浏览器。

如需恢复一张干净的画布，使用「文件 → 清空画布」。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 选择工具 | `V` |
| 新建元素 | `C` |
| 删除所选 | `Delete` / `Backspace` |
| 平移画布 | 拖动空白处 / `Space` + 拖动 |
| 缩放 | 滚轮 / `+` `-` |
| 适应画布 | `F` |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` |
| 取消当前操作 | `Esc` |

```
favicon.svg   站点图标
```

## 说明

- 数据默认保存在浏览器的 `localStorage` 中，不会上传到任何服务器。
- 推荐使用新版 Chrome、Edge、Firefox 或 Safari。
- 导入 JSON 会替换当前画布，该操作可以撤销。
