# Classo · UML 绘图工具

一个不依赖任何框架或外部资源的 UML 绘图工具，支持**类图**与**时序图**，使用原生 HTML + CSS + JavaScript 编写。直接双击 `index.html` 即可使用。

通过顶栏的「类图 / 时序图」切换两种工作台。两种图表各自保存数据、各自维护撤销历史，互不影响；当前所在的模式也会被记住。

## 我的图表

点击顶栏的「我的图表」打开本地图库，查看和管理之前创建过的所有图表。

- **按类型分类**：图库分为「类图」与「时序图」两组，并可通过顶部分类标签快速筛选
- **缩略图卡片**：每张图表显示结构缩略图、名称、类型、元素 / 参与者和关系 / 消息数量，以及最近更新时间
- **打开图表**：点击卡片预览或「打开」即可载入对应工作台；如果是另一种图表类型，会自动切换到对应模式
- **新建空白图**：在「我的图表」中点击「新建类图」或「新建时序图」会创建一张空白图表并立即打开
- **管理图表**：支持重命名（双击标题也可）、复制副本、删除；删除前需要二次确认
- **当前图表**：同一类型下会记住最近打开的那张图，卡片上以「当前」标记
- **自动迁移**：此前版本保存在单个键中的类图 / 时序图数据，会在首次打开时自动迁移为「我的类图」「我的时序图」
- **自动保存**：对当前图表的编辑会自动写回图库，不需要手动保存

## 类图功能

- **元素类型**：可创建类、接口、抽象类和枚举，并在右侧属性面板中随时切换
- **类型化面板**：类、接口与抽象类配置属性和方法（接口属性默认公开），枚举使用独立的枚举值列表
- **画布表现**：接口自动显示 `«interface»`，枚举显示 `«enumeration»`，抽象类显示 `«abstract»` 且名称使用斜体
- **结构化成员编辑**：属性和方法通过表单添加与编辑，修饰符用下拉选择，无需手动输入 `+ - # ~` 符号
- **多参数方法**：点击「添加参数」可为方法逐个添加参数，参数会自动以逗号连接；也可在参数框中按回车继续添加
- **方法标记**：方法可标记为虚函数或抽象方法，分别显示在方法名前的 `virtual`、`abstract`，抽象方法同时使用斜体
- **六种关系**：关联、继承/泛化、实现、聚合、组合、依赖
- **关系属性**：类型、标签、两端重数，可一键交换方向
- **智能排版**：自动选择连接边、正交折线、自动绕让；拖动时吸附对齐并显示参考线
- **画布操作**：自由平移、滚轮缩放、适应画布
- **编辑体验**：撤销 / 重做、删除、方向键微调、自动保存到浏览器
- **文件**：导入 / 导出 JSON，导出 SVG 与 2× PNG

## 时序图功能

- **五种参与者类型**：参与者（小人图标）、对象、边界、控制、实体；对象类标题会自动显示 `«boundary»`、`«control»` 或 `«entity»`
- **生命线**：参与者下方自动生成虚线生命线，所有消息沿时间轴自上而下排列
- **三种消息**：同步消息（实线 + 实心箭头）、异步消息（实线 + 开放箭头）、返回消息（虚线 + 开放箭头）
- **点击连线**：选择消息工具后，先点击发送方、再点击接收方即可创建消息；连续点击同一参与者两次可创建自调用消息
- **自动激活条**：同步消息会为接收方生成激活条，并与后续返回消息、下一段调用自动配对合并
- **消息排序**：拖动消息线可直接调整先后顺序，也可在属性面板中使用上移 / 下移或方向键
- **参与者排序**：拖动参与者标题即可左右调整顺序，也可在属性面板中使用左移 / 右移
- **属性编辑**：参与者名称、类型、主题色；消息内容、类型、发送方、接收方，可一键交换两端
- **画布操作**：拖动空白平移、滚轮缩放、适应画布
- **编辑体验**：撤销 / 重做、删除、自动保存；删除参与者会级联删除其相关消息
- **文件**：导入 / 导出 JSON，导出 SVG 与 2× PNG
- **示例图**：首次进入时序图会载入一张登录流程示例

## 使用

1. 打开 `index.html`，首次进入会显示一张类图示例。
2. 点击顶栏「我的图表」查看之前创建的所有图表，按类图 / 时序图分类浏览；点击卡片即可打开，或使用「新建类图 / 新建时序图」创建空白图表。
3. 通过顶栏的「类图 / 时序图」切换工作台。
4. **类图**：点击右上角「新建元素」或双击画布空白处添加元素；在右侧属性面板中填写名称并选择元素类型。点击左侧「关系」中的类型，再依次点击起点元素和终点元素即可连线。
5. **时序图**：点击右上角「新建参与者」或双击画布空白处添加参与者；在右侧属性面板中修改名称与类型。点击左侧「消息」中的类型，再依次点击发送方与接收方即可创建消息。
6. 所有修改都会自动保存到「我的图表」中的当前图表，撤销 / 重做与导入导出对当前工作台生效。

如需清空当前图表，使用当前工作台的「文件 → 清空画布」；示例内容可通过「文件 → 加载示例」重新载入到当前图表。

## 快捷键

### 通用

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` |
| 立即保存 | `Ctrl/⌘ + S` |
| 适应画布 | `F` |
| 缩放 | 滚轮 / `+` `-` |
| 取消当前操作 / 取消选择 | `Esc` |

### 类图

| 操作 | 快捷键 |
| --- | --- |
| 选择工具 | `V` |
| 新建元素 | `C` |
| 删除所选 | `Delete` / `Backspace` |
| 平移画布 | 拖动空白处 / `Space` + 拖动 |
| 微调位置 | 方向键（`Shift` 加速） |

### 时序图

| 操作 | 快捷键 |
| --- | --- |
| 选择工具 | `V` |
| 新建参与者 | `L` |
| 同步 / 异步 / 返回消息 | `1` / `2` / `3` |
| 删除所选 | `Delete` / `Backspace` |
| 调整消息顺序 | `↑` / `↓` |
| 调整参与者顺序 | `←` / `→` |
| 平移画布 | 拖动空白处 / `Space` + 拖动 |

## 目录

```
index.html    页面结构（两种图表工作台与图表库）
styles.css    界面、画布与图表库样式
shell.js      类图 / 时序图模式切换
library.js    图表库：索引、缩略图、分类、新建与图表管理
app.js        类图的绘图、交互、存储与导出逻辑
sequence.js   时序图的布局、交互、存储与导出逻辑
favicon.svg   站点图标
```

## 说明

- 图表库索引、缩略图信息与每张图表的数据都保存在浏览器的 `localStorage` 中，不会上传到任何服务器。
- 旧版本的单张类图 / 时序图数据会在首次打开时自动迁移进图表库，原始数据键会保留作为备份。
- 推荐使用新版 Chrome、Edge、Firefox 或 Safari。
- 导入 JSON 只会替换当前图表的内容，该操作可以撤销。
- 时序图的激活条由同步消息自动推导，无需手动维护。
